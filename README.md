
<h1 align="center">DevBills api</h1>

Esta API fornece endpoints para gerenciar dados financeiros, como transações e categorias, para um dashboard financeiro. O projeto utiliza TypeScript para segurança de tipos, Express para o servidor, MongoDB para armazenamento de dados, e Docker para a configuração do banco de dados.

# Tecnologias Utilizadas
+ TypeScript: Superset do JavaScript que adiciona tipagem estática.
+ Express: Framework para construção de APIs em Node.js.
+ Mongoose: Biblioteca de modelagem de objetos MongoDB para Node.js.
+ Zod: Biblioteca de validação de esquemas.
+ dotenv: Gerenciamento de variáveis de ambiente.
+ cors: Middleware para configurar o Cross-Origin Resource Sharing.
+ Docker: Plataforma para execução de contêineres, usada para rodar o MongoDB.
